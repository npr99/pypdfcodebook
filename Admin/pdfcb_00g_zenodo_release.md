1. Connect GitHub to Zenodo
- Log in with your Zenodo account and authorize GitHub.
- Go to https://zenodo.org/account/settings/github/.
- Select the repository you want to archive and enable Zenodo for it.
- May need to sync Zenodo with GitHub and reload page

2. Create a Release on GitHub
- In your GitHub repo, go to Releases → Draft a new release.
- Tag the version (e.g., v1.0.0) and publish the release.
- Zenodo will automatically archive this release and generate a DOI.
